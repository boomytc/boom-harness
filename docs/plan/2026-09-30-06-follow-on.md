# 按条实现后续 seam

> 八条各自合并。开工某一条之前，先把 [../design/2026-09-30-follow-on-seams.md](../design/2026-09-30-follow-on-seams.md) 里该条扩成单独 design，再改代码。

## 目标

- 每一条都有规格里的验收测试。
- 关掉对应 boom 插件或选项后，默认行为回到挂载前。

## 非目标

- 把八条打进同一次改动。
- 决策 0002 排除的运行时、UI 和账号。

## 背景与依据

落点已在 follow-on design。

## 任务分解

- [ ] 沙箱补强：文件 confine 仍按次调用。没有 runner 时沿用 `SANDBOX_UNAVAILABLE`。拒绝改名绕过，拒绝写 `$DSH_HOME` 下的 memory、权限规则存储和钩子配置。子进程网络与模型 API 的允许列表分开，且都不是 `SandboxPolicy` 字段。不在宿主进程启动时套内核沙箱。验收规格 US-4。
- [ ] hunk 归属：用代理写完后的副本和轮次结束副本区分 `user-on-agent-file`。`workspace/attribution` 按会话事件声明。Host 重启后仍能读到。验收 US-2。
- [ ] 工具结果双份：模型投影不写入 `tool/result`。现有 `content` 仍是日志结果。`updatedToolOutput` 接到这条投影。验收 US-3。
- [ ] 子代理 worktree：默认 `shared`。`worktree` 改 `subagent-spawn-in-process`、`subagent-acp`、`subagent-dsh-sdk`、`subagent-codex`、`subagent-claude-code` 的 cwd 来源，并用 `git worktree add`。`apply` 冲突则 `merge --abort`。验收 US-1。
- [ ] 停止门：在 `agent/turn-stopping` 上 `steer`。来源不是 `user`，消息写入日志。路径来自 goal 或会话配置。验收 US-5。
- [ ] 架构棘轮：只检查 `packages/boom/**` 的新增违规。验收 US-6。
- [ ] 模型重试续跑：未配对的 `llm/retry` 在 `resume` 时不追加 closer 里的 `step/end` 与 `turn/end`。按 `delayMs` 重新等待，或追加原来的 `llm/retry-started`。验收 US-7。
- [ ] 技能正文扫描：`renderSkillContent` 的两个调用方都在渲染前扫描。与已提交夹具全文相同才不注入。其余放行。验收 US-8。

## 风险与依赖

- 沙箱补强应先于把记忆和规则当作已隔离的对外承诺。
- worktree 与停止门会改 `subagent` 与 `agent-loop` 的选项。每条单独开分支，便于跟 `upstream/master` 合并。
- 某一条若必须改动的核心面超出 design 的点名范围，先补 decision，再写代码。
